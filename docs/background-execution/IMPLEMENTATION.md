# 后台执行机制

后台设置统一保存音频、画中画和定位选择。新安装默认启用音频和后台常驻，定位与待命实时活动默认关闭；已保存选择保持不变。系统后台任务选项不在产品界面展示，旧开启状态按关闭处理。

## 配置与执行资格

配置迁移保留显式空集与可识别 schema 中的未知值；损坏或未来版本配置不自动启权、不覆盖原数据。每轮任务持有独立 lease；设置新增项不加入已开始的轮次，取消项立即撤销旧轮次贡献。常驻需求与任务需求独立，不能借用其他轮次的执行资格。

音频播放和 PiP 启动分别提供实际回执，未取得回执时不能视为可后台执行。共享音频会话按 owner/generation 串行获取和释放，最后一个 owner 才停用。PiP 停止与新实例创建串行处理；超时不是停止证据，迟到回调不能操作新实例。

系统资格到期、锁屏、手动停止与未知结果仍可暂停运行。状态更新或实时活动展示不延长执行时间；scene 变化不自动重试已拒绝的系统申请。

## 定位

用户开启定位选项时可请求 WhenInUse；授权本身不启动定位，仅任务或常驻需求驱动。请求遵循共享权限 gate，不排队连弹。拒绝时提供系统设置入口；关闭后的迟到授权不能重新开启选项或恢复已结束需求。后台和 Siri 不发起首次权限弹窗。

定位只在内存中使用时间戳与精度作为执行来源证据，不保存或上传坐标。首次回执必须属于本轮、有限、非未来且足够新；静止无回调不直接视为失效。定位失败不撤销其他独立来源，也不通过反复 stop/start 强行恢复。

## 验证边界

合成测试覆盖配置迁移、权限门控、迟到回调和轮次隔离；模拟器原生权限用例确认了无任务时由开关请求定位，以及拒绝后其他方式仍可使用。

真实设备持续定位、静止和弱定位、耗电温度、音频中断/蓝牙路由、PiP 共享会话及长时间 CoreDevice/VPN 控制仍需独立验收。系统允许的技术调用不代表无限后台运行、强制退出后唤醒或已满足分发要求。
