重点语义：

1. 新装定位默认选中不能自动变成授权或生效。旧三项显式选择迁移为各自单项；明确空集必须重启保留。旧 systemTask + resident 不再隐式启动音频，UI 解释这种变化。
2. 已知 schema 的未知字符串要 round-trip；未来 schema 禁止当前版本写回；损坏配置不自动启权；旧 key 保留。只有历史文件存在性检测，不读取历史内容或 Keychain。
3. 取消某项应立即撤销所有当前 run 对该项的资格，重新勾选不得给同一 run 加回；resident 的重新勾选与旧 run 的永久否决需分离。
4. 音频/PiP 的共享 session、不同 run、resident 的所有权要分别审查。终止一个不能误停其他有效 owner；晚到回调不能复活已结束 demand。
5. 定位授权只能在明确前台任务/驻留启用操作内发生；不后台弹窗，不申请 Always 或精确定位升级，不在前一个权限弹窗结束后排队自动弹下一个。
6. 定位第一次证据要求时间戳在本轮开始后、非未来、距接收不超过 5 秒且精度有限非负。静止不回调不等于失效。`locationUnknown` 撤贡献等待自然恢复，不能 stop/start 自旋。
7. 原生 continued processing 取消/到期不清楚时暂停整轮，即便还有音频/定位且当前前台；普通申请拒绝或短期交接到期则只损失该来源。不自动换源续跑被系统取消的任务，不自动重放动作。
8. 当前方案技术可用性与 App Store 后台用途要求不能混为一谈；不承诺永久保活。
