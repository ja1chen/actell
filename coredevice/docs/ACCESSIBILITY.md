# 只读无障碍观察

“手机操控”中的“包含屏幕无障碍内容”默认关闭。开启后，本地模型任务的截图结果会尝试附带一次独立的原生无障碍快照。无障碍文本和结构可能包含屏幕外内容，并与截图一起发送给所选模型服务商。会话记录只保留快照状态和节点数量；模型运行中的最新观察仍会包含节点内容。Muse 远程截图不附带该观察。

读取复用现有配对、隧道和 RSD 服务目录，通过 `com.apple.accessibility.axAuditDaemon.remoteAXService` 的原始 DTX 连接执行只读 AXP 请求，不启动 XCTest Runner，也不发送 AX 按压或滚动操作。首版将产品读取限制在 iOS 27.0、系统构建 `24A437` 与 AX API 26 的组合；其他组合明确报告不可用。开发者模式、开发者服务和当前连接路线仍是前提；首次配对和开发者镜像准备不因此变为免电脑。

## 观察边界

- 读取先对主显示器中心点执行无触摸命中测试，取得该点所属进程的应用根和深快照，再检查根、命中进程及显示几何是否变化。中心命中不是前台 App 的可靠证明；键盘、弹窗或浮层可能属于其他进程。结果保留命中方式、点和 PID，明确 `foregroundAppConfirmed=false`。
- 快照只覆盖选定进程暴露的无障碍信息，不代表完整屏幕、所有窗口或完整 DOM。外部进程仅保留已识别的终端引用，不补造子树。
- 截图和树分开采集，`atomic=false`；根稳定不代表页面内容未变化。原生 frame 使用逻辑点，显示方向和截图像素映射尚未验证，不能直接用于点击。触控仍使用已有截图坐标和授权流程。
- 每次读取使用新的服务连接与应用根；节点 ID 仅在对应快照内有效，设备内部 token 不交给模型或写入会话记录。字段缺失、null、false、零和空字符串分别保留；超限或结构不符时不输出被截断的成功树。
- AX 失败时截图仍可用，并向模型返回来源和失败类别，不把失败表示成空页面。停止订阅确认与本地写端关闭分别报告；没有确认不能记为成功停止，也不把本地关闭写成远端确认。已建立会话的读取异常不自动切换 VPN、重新配对或重放输入。

## 实现与验证

`coredevice/rust/src/ax_dtx.rs` 对控制会话、语义回复和分片施加边界；`ax_archive.rs` 将 NSKeyedArchiver 对象表解析为普通数据而非实例化私有类；`ax_snapshot.rs` 校验层级并生成快照内路径。归档 UID 图与二进制 plist 容器分别设置深度上限。每个会话只允许一个在途语义请求，超时或响应不一致后关闭该连接。

真实设备已验证本机回环通道、协议协商、指定 PID 和中心命中读取，以及固定测试页面的文本、标识和可用矩形。竖屏固定页面的单个按钮叠加位置与截图相符；受限后台执行窗口内曾读取系统设置进程。通用几何映射、横屏、显示缩放、第三方 App、长期后台、首次授权历史与重启恢复仍需分别验证，不能由上述结果推断。
