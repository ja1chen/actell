# 控制会话停止与完成展示

## 媒体停止

仅关闭本地 DisplayService/HID 连接不能证明远端查看已停止。受控实测区分了停止标识：发送本地 SSRC 后会话仍存在，发送协商得到的 RemoteSSRC 后远端会话被移除。

实现保存当前流的 RemoteSSRC，在新的 DisplayService 连接上定向停止，并校验返回会话列表不再包含本流。无效回复或本流仍存在时不报告成功。不使用全局 stopAll，不影响其他控制端；认证隧道可继续为下一任务服务。单次截图/点击验证复用同一释放链路。

断线或直接关闭 transport 仍只证明本地撤销；无法完成定向停止时，远端结果保持未确认。

## 完成与执行资源

任务先提交终态并等待已排队的活动更新返回，再释放执行资格、控制服务和媒体。等待期间主动停止仍按 generation 撤销旧收尾。独立任务活动在完成、中断、阻止或停止后立即结束并移除，后台完成可先提交一次提醒，不等待返回前台或下一轮任务。显式开启的待命活动复用同一实例，任务结束后清除任务身份并恢复待命；关闭待命时先保留正在执行的任务，结束后移除活动。进程启动时立即清理上次遗留的活动，不恢复旧轮次的执行权限。

ActivityKit 请求返回、系统内容更新和用户实际看到画面是不同证据。已观察到仅有后台媒体资格时普通更新被系统拒绝；短时 UIKit 后台任务和等待不能保证消除该拒绝。另有实测终态被系统接收，因此不能将所有“完成未显示”都归结为同一原因，也不能把观察到的时间窗口当作系统公开固定限制。

诊断按活动/运行标识、写入序号和内容时间关联请求、返回、系统内容变化与扩展计算；不得用缺失日志证明事件未发生。尚缺少视觉与系统事件同时对应的情况，继续保留未定位状态。

## 完成后的导航

正常任务完成时发布对应会话的导航事件；后台完成可在释放当前控制所有权前，通过既有认证服务尝试返回 App。连接不可用或其他任务持有设备时跳过，不为普通聊天重新建立控制连接。返回失败不改变已完成结果、不重试输入；失败、停止或到期不触发该完成返回。

导航定位到会话末尾，保留审批归属与失效校验；历史阅读、键盘和卡片展开不应被持续强制吸底。模拟器回归证明本地导航与清理顺序，真实唤回及系统展示需独立验证。
