# 兼容性与验证结论

这里保留可复用的验证结论。构建、合成对端、系统模拟器与真实设备的证据分别成立，不能互相替代。

| 范围 | 已得到的结论 | 边界 |
| --- | --- | --- |
| ESP32 NCM | 实际链路曾完成认证、视频截图和前台测试按钮触摸；受控后台场景获得静态与变化画面 | 不代表所有板卡、长时间后台、拖动或完整模型任务均通过 |
| VPN 回环 | 复用系统配对身份获得截图、实际点击效果和媒体释放 | 需要外部 VPN、本地接口及服务发现匹配；蜂窝切换和长期后台独立验收 |
| USB HID | 描述符、输入状态机、心跳、停止与断线行为有生产源码回归 | USB transfer completion 不证明 iOS UI 生效；真实拖动/停止释放需要硬件验证 |
| 服务发现 | IPv4/IPv6、过期与失效候选、绑定接口均有检查 | 无候选不能证明目标未提供任何开发者服务；不可据此猜测端口 |
| 视频 | 内容矩形裁剪、静态帧确认及适配 NCM 带宽的策略有实测依据 | 私有格式可能随系统变化；详见 [几何与帧完整性](VIDEO-GEOMETRY.md) |
| 清理 | 定向停止使用协商标识并核对远端会话；本地关闭不重放输入 | 异常断线可能无法完成远端确认，不以 socket 关闭推断远端停止 |

首次 DDI 准备、重启恢复、资源峰值、并发/长时间运行和完整任务闭环仍需各自验收。测试身份、mock 帧或构建成功不记作物理设备成功。
